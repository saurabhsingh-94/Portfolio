# Saurabh Kumar Singh Portfolio — Product Specification

## 1. Purpose

Provide a high-impact, professional creative developer portfolio for Saurabh Kumar Singh while establishing a clean, tactile block visual identity.

The portfolio presents:
- Production Web3 projects & dApps
- Interactive DLT visualizers & CLI utilities
- Open-source prototypes and smart contract dev tools
- Verified technical certifications (Hashgraph Association, HackerRank)

---

## 2. Experience Principles

- **Tactile Block Identity**: White-space led composition, 3D block elements, red accenting, and smooth loading transitions.
- **Honest Status Badges**: Every project clearly displays exactly one label (`Production`, `Prototype`, `Experiment`, `In Progress`).
- **Resilient Fallbacks**: 3D `<model-viewer>` falls back gracefully to high-performance Canvas 3D particle nodes.

---

## 3. Structured Data Model

`data/projects.json` is the canonical inventory driving project cards and filters. Every record follows the standard schema with ownership, status, summary, whatItIs, whyItExists, problem, solution, technologies, role, and links.
