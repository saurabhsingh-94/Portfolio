A creative developer portfolio combining blockchain development, smart contract security, real-time DLT visualizers, and interactive 3D presentations.

Built as a zero-framework, static portfolio showcasing real public projects, open-source repositories, and verified technical credentials.

---

## 🚀 Featured Projects

### 1. Argentum [Ag]
A Web3 social platform ("Twitter for Devs") for builders to post real-time update logs and anchor proof of work on-chain.
- **Status**: Prototype
- **Stack**: TypeScript, React, Next.js, Solidity, IPFS, Ethers.js

### 2. Hedera Multi-Chain Visualizer
Real-time cross-chain consensus & network throughput visualizer covering Hedera Hashgraph, Bitcoin, Ethereum, Solana, and Polygon.
- **Status**: Production
- **Stack**: JavaScript (ES6+), Canvas API, WebSockets, Hedera SDK

### 3. NexaDeFi Platform & DEX Swap
Full-stack Web3 Decentralized Finance dashboard featuring automated DEX token swaps, staking liquidity pools, and MetaMask integration.
- **Status**: Production
- **Stack**: Next.js, React, Tailwind CSS, Ethers.js, Solidity

### 4. Crypto Portfolio Tracker CLI
Terminal-based cryptocurrency portfolio manager powered by CoinGecko API and Hedera Token Service (HTS).
- **Status**: Production
- **Stack**: Python 3, CoinGecko REST API, Hedera HTS SDK

### 5. Debugr — Smart Contract Inspector
Interactive developer suite for dissecting EVM smart contract execution traces, decoding ABI function calls, and highlighting storage state diffs.
- **Status**: Prototype
- **Stack**: TypeScript, React, Node.js, Ethers.js

### 6. Open Dev Data Taxonomy
An open taxonomy, metric framework, and dataset mapping cryptocurrency, blockchain, and decentralized ecosystems.
- **Status**: Experiment
- **Stack**: JSON Schema, YAML, Markdown

## 💻 Run Locally

Serve the repository over HTTP:

```bash
npx -y serve ./
```

Or using Python:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/`. There is no build step or framework installation required.
