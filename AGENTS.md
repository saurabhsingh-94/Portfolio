# AGENTS.md — Repository Guidelines & Agent Workflows

## Codebase Principles
1. Zero framework build steps — pure HTML5, CSS3, ES6 JavaScript.
2. Structured project metadata must reside in `data/projects.json`.
3. Dedicated case study pages belong under `projects/*.html`.
4. Maintain responsive design across mobile (375px), tablet (768px), and desktop (1440px).
