Crypto Portfolio Tracker CLI

A lightweight terminal utility for tracking multi-currency cryptocurrency portfolios, live market rates, trending coins, and Hedera HTS token balances.

1. What It Is

A Python CLI application that queries live pricing data from the CoinGecko REST API and Hedera Token Service (HTS) to provide real-time portfolio valuation, P&L calculations, and target progress tracking.

2. Why It Exists

Developers constantly working in shell environments need a rapid, lightweight tool to check asset performance without opening heavy web browsers or exposing private API keys to third-party web trackers.

3. Problem

Web portfolio applications often consume hundreds of megabytes of RAM and require persistent browser tabs. CLI tools need to be sub-second, resilient to API rate limits, and visually clear.

4. Solution

Built a modular Python engine with JSON-based portfolio persistence, multi-currency conversion math (USD, INR, EUR, GBP), Colorama terminal formatting, and error handling for REST timeouts.

5. Experience Created

An aesthetic, colorized terminal table presenting live coin prices, 24h percentage shifts, portfolio totals, and progress bars.
