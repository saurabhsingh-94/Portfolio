Open Dev Data Taxonomy

An open taxonomy and dataset specification categorizing cryptocurrency ecosystems, developer metrics, and protocol architecture.

1. What It Is

Open Dev Data is a standardized categorization schema for open-source cryptocurrency repositories, developer activity metrics, and protocol infrastructure layers.

2. Why It Exists

Analyzing open-source ecosystem growth across thousands of independent GitHub organizations requires a unified data schema to track active contributors, commit frequency, and protocol dependencies.

3. Problem

Decentralized ecosystem metrics are fragmented, making cross-chain comparisons inconsistent or biased toward single metrics like star counts.

4. Solution

Designed a hierarchical taxonomy mapping projects into Layer 0/1/2 infrastructure, smart contract primitives, tooling, and application layers with JSON/YAML schema definitions.

5. Experience Created

An open, documented taxonomy specification for researchers and Web3 analysts.
