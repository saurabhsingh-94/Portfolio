Debugr — Smart Contract Inspector

Interactive developer tool suite for dissecting EVM smart contract execution traces, decoding ABI function calls, and highlighting state mutations.

1. What It Is

Debugr is a developer inspection platform designed to parse EVM transaction logs, match raw bytes against contract ABIs, and display readable state changes.

2. Why It Exists

Auditing smart contract behavior on testnet requires rapid feedback on storage slot changes, internal call stacks, and re-entrancy risks.

3. Problem

Raw execution traces on public block explorers are formatted for machine consumption, making security analysis tedious for developers.

4. Solution

Created an ABI decoding pipeline in TypeScript that maps event logs, decodes function arguments, and renders storage diffs.

5. Experience Created

A side-by-side inspection view with step-by-step transaction trace highlights and storage mutation flags.
